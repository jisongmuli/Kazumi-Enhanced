# Windows 弹幕

默认配置使用随 Windows 便携包提供的本机 Node 多源服务；无需手动填写接口或弹弹play密钥。播放器中打开“选择弹幕源”，搜索番剧，选择对应来源，再选择分集。相同名称可能同时有动漫和真人剧，请按来源标题确认。

`v2.3.8-enhanced.4` 修复了以下问题：

- 本机及兼容接口返回的 `episodeNumber` 可能是文本（例如 `"195"`）。客户端现在同时支持整数、文本集号及无集号的特别篇，避免分集列表解析失败。
- 本机服务不再沿用公共服务器默认每分钟 3 次的读取限制。调整仅作用于播放器自行启动、随机令牌保护的本机服务，不修改手动配置的外部服务限制。
- 本机 `[bilibili]` / `[bilibili1]` 标签按播放器的 `BiliBili` 名称识别，哔哩哔哩来源开关可正常控制这些弹幕。
- 切换失败时保留当前弹幕；分集加载及弹幕读取的错误会显示具体原因，不再只提示笼统失败。

自动回归测试覆盖 Windows 弹幕面板“搜索 → 番剧 → 分集 → 选集 → 启用定时弹幕”，以及文本集号、整数集号、源标签和请求失败后的状态。

显式联网验证：

```powershell
flutter test --no-pub tools/windows_danmaku_live_test.dart
```

需要已安装的 `build/windows/x64/runner/Release/danmaku_engine`。探测调用应用使用的同一个服务启动器和弹幕 API，在临时独立配置中连续读取四个不同分集，不读取或修改用户设置，不记录令牌或弹幕文本。设置 `KAZUMI_VERIFY_DIR` 可保存数量和时间范围报告。

来源无弹幕、来源验证或真实网络故障仍可能导致空结果或请求失败，可选择其他分集/来源，或在“设置 → 弹幕接口”配置自己的兼容服务。
