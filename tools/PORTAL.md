# 浅色视频门户主页

用户选择第 2 版设计，入口为 `/tab/home/`。应用首次升级到此布局时切换为浅色蓝色主题，旧版默认推荐页改为新首页；用户原有播放、片源、收藏与观看记录保留。

## 交互与数据

| 界面操作 | 实际行为 |
| --- | --- |
| 首页、动漫、影视、短剧、YouTube、我的 | 独立路由和页面状态；我的接原有个人页 |
| 顶部搜索，按 Enter 或搜索图标 | 并行检索 Bangumi 动漫目录、影视站、红果官方和 YouTube；可切换结果类型 |
| 国产/日本动漫、动漫电影、动画短片 | 向 Bangumi 发送真实国家或形式标签，20 条一页 |
| 华语/海外电影、国产/海外剧集、纪录片、综艺 | 读取来源公布的分类和地区链接，再查询对应页面；首页推荐来源优先 LIBVIO，失败后尝试已收录的其他地址 |
| 热门短剧 | 红果官方网页目录；仅播放网页公开开放的集数 |
| YouTube 精选 | yt-dlp 读取公开视频标题、频道、封面、时长；主题检索与链接检索可用，画质沿用播放器的真实分辨率菜单 |
| 轮播圆点、左右按钮、自动轮播 | 切换真实内容，每 8 秒轮播；悬停或被播放页覆盖时暂停 |
| 立即播放 | 有历史则续播；动漫打开片源检索/选择，影视读取播放列表，YouTube 进入原有播放器 |
| 海报 | 动漫/影视打开详情与选集，YouTube 直接进入播放器 |
| 继续观看 | 按真实历史恢复原片源、集数及进度；仓库变更自动更新主页 |
| 观看记录、查看全部 | 进入完整历史页或对应的内容目录 |
| 刷新、重试、加载更多 | 实际重新请求或分页；旧搜索取消后不能覆盖新结果，部分失败不会清空其他结果 |
| 更多菜单 | 时间表、我的追番、45 个片源目录、高级动漫搜索和设置 |

评分只在来源提供时显示；提示区分 Bangumi 评分与网站自身评分，不生成示例分数。影片集数/清晰度说明使用来源原始标记。主页内容是公开热度目录与主题检索，未声称提供个性化推荐算法。

## 观看进度兼容

`Progress` 新增 Hive 字段 4 `durationMs`，默认值 0。新播放使用播放器测得的真实总时长显示进度比例；旧记录总时长未知时只显示已看到的时间，不猜测百分比。旧版本历史文件可继续读取。

## 验证

普通测试包含路由标识、导航与搜索提交、请求取消、部分失败、分类查询、分页去重、实际播放参数、轮播切换、历史比例及 1280/840/390 宽度布局。

显式联网验证：`flutter test --no-pub tools/portal_live_test.dart`，设置 `KAZUMI_VERIFY_DIR`、`KAZUMI_YOUTUBE_ENGINE`、`HTTPS_PROXY`。该探测加载实际目录与封面并渲染主页，不进入普通离线测试。

报告与渲染图位于 `verification/portal-live-results.json`、`portal-1280.png`、`portal-390.png`。这些是实际 Flutter 页面渲染，不是 AI 设计图。
