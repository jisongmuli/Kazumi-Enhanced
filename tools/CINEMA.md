# 影视片源与官方短剧

Windows 应用的侧栏新增“影视”，用大封面网格展示每部影片。宽窗口约六列，窄窗口自动调整；卡片显示片名、片源和站点提供的更新标记。

- 从 [果汁实验室目录](http://guozhivip.com/mvs.html) 整理截图中的 22 个名称，合并同址的“看剧AI / 在线看剧”，共 21 个独立网站。
- 原有 21 条片源全部保留，新增 24 个影视片源、官方短剧与公告入口，总计 45 个入口。新增网站依据 [awesome-zhuiju-free](https://github.com/laoma528/awesome-zhuiju-free/blob/main/resources/resources.json)，在本机再次探测；备用网址依据网站自己的公告，例如 [LIBVIO 公告](https://libvio.lol/) 与 [饭搭子公告](https://fdzys666.xyz/)。每条新增来源记录 `discoveredFrom`，没有自动用新网址覆盖旧网址。
- 选择全部或单个片源，搜索影片；单个片源的搜索结果有分页时可加载更多。
- 点击封面进入影片详情，选择线路与集数后使用现有播放器。影视记录可从观看历史继续播放。
- 首页与搜索使用公开页面，解析页面实际搜索表单；饭搭子的搜索路径使用该站页面公布的格式。没有使用未授权账号、浏览器私有 Cookie 或会员凭据。
- 标准 JSON 播放配置中的直接媒体地址可交给播放器；其他播放器使用现有 WebView 解析流程。打开原站可访问尚未识别的播放方式。

## 验证范围（2026-10-12）

45 个入口的本机实时检查中，26 个可读取影片封面，24 个可提取示例影片的播放列表（包含同站备用网址）。新增可读取的来源包括爱电影、奈菲影视、PPnix、光速影视、剧踪影院、片库、66大片网、嘀嗒影视、开心影院、豆花电影网、樱之空、西瓜影视、红果官方及 LIBVIO 的 4 个公告入口。部分网站的播放方式尚不能直接解析；可在详情页打开原站。

独播库 720p、555电影 1080p 和红果官方 720p 的视频与 AAC 音频已通过本机 libmpv 流式播放验证；不代表每个影片或每条线路都稳定。

## 红果短剧

加入的是 [红果官方网页](https://hongguoduanju.com/)，原官方域名 `novelquickapp.com` 指向此入口。影视顶部有“红果短剧”快捷按钮。首页读取到 27 部封面，搜索“凡人”读取到 10 个结果；搜索地址按官方前端路由 `/search/关键词` 解析。

点击封面可查看详情及官方网页开放的集数。示例《烛九阴第七季》网页开放 3 集，首集 720p 视频与音频验证通过。未列出网页禁用的集数，也没有构造 App 受限集数的播放地址；更多剧集请按官方提示在红果 App 观看。

饭搭子 net/com 两个入口搜索“凡人”均读取到 20 个结果。麦田搜索要求验证码，会显示验证提示，不再误报零结果。Auete 最新 Dart 请求因站点证书过期失败。部分入口涉及 HTTP 拒绝、浏览器验证、动态页面或地址公告，栏目保留名称、状态与原站入口。没有关闭 TLS 证书校验。

`test/cinema_test.dart` 覆盖封面去重、广告与文章过滤、搜索参数、线路分组、官方红果媒体数据解析、历史标识、搜索取消、单源失败，以及 390/1218 像素布局和搜索入口。

开发验证工具：

```powershell
. E:\KazumiTools\Environment.ps1
$env:KAZUMI_VERIFY_DIR = 'E:\KazumiTools\verification'
flutter test --no-pub tools/cinema_live_test.dart
```

上面的实时探测会访问全部片源，不属于离线测试。可以设置 `KAZUMI_CINEMA_SOURCES=guozhi1,guozhi7` 只检查指定来源。`probe_cinema.py` 使用实时探测导出的媒体地址检查播放器，不保存视频。

来源列表保存在 `assets/cinema_sources.json`。站点改域名时按公告添加额外入口，保留旧条目；页面结构变化仍需要解析适配，不将站点错误永久当作无影片。
